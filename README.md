# Forme

A local-first agent that turns your knowledge base's drift into **one-decision cards** — evidence + minimal diff + accept/park/reject — and learns your taste from every decision you make.

**Status: pre-release, building in private. Public launch ~Aug 2026.**

- **Your notes stay yours.** Markdown in, markdown out. Runs on your own agent runtime (Codex CLI first). No cloud, no database.
- **One decision at a time.** The agent proposes; you decide with a single keystroke. Time-to-decision is measured, not assumed.
- **It learns.** Repeated suggestions go to zero by construction; your decision history distills into taste rules you can read and edit.

_Full docs, demo, and the six-week self-experiment behind this design land here at public launch._
