# Forme

Forme is a local-first **Living Project Twin**: durable project state that survives any one document, chat, runtime session, or model. It keeps evidence and owner-confirmed meaning distinct from agent inference, supports bounded reversible action, and produces controlled external projections.

**Status: pre-release. MVP demo and public-launch target: August 15, 2026.**

- **Continuity.** Reconstruct Now, What Changed, and Next Move after interruption.
- **Cognition.** Surface cross-time interpretations with evidence, uncertainty, and correction.
- **Bounded agency.** Agents propose; Forme-owned effectors validate, execute, receipt, and roll back.
- **Controlled presence.** External projections compile from an explicit allowlist, never ambient private context.
- **Runtime choice.** Codex and OpenCode are first-class execution runtimes behind a Forme-owned semantic and authorization boundary.

The existing decision-card flow remains a validated control primitive inside the Twin; it is no longer the product boundary.
